# V2 Development

V2 is a future development stage and is intentionally separate from the V1 amplifier.

## Goal

Explore a modular digital extension while keeping the basic analog V1 amplifier understandable and usable on its own.

## Possible Features

- ESP32-based digital control
- OLED display
- Digital EQ
- Digital effects
- Additional controls
- More advanced user interface
- Modular audio processing

## Design Principle

V2 should not hide the fundamentals learned from V1. The NTE451 preamp and LM386 amplifier remain useful reference points for understanding the analog signal path.

A modular approach is preferred so that experiments with the digital section do not make the V1 amplifier unusable.

## Not Yet Implemented

The V2 design is not finalized. Exact ESP32 hardware, audio conversion method, firmware architecture, controls, and enclosure design will be documented after V1 is electrically and acoustically validated.

No V2 hardware or software is claimed to be complete at this stage.
